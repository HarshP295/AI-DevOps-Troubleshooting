# Incident INC-4821
**Date**: 2026-08-14
**Service**: PaymentService
**Symptom**: PaymentService returning 503 Service Unavailable errors. High latency on checkout.
**Root Cause**: Database connection pool exhaustion. Max pool size was set too low in deployment v1.8.2.
**Resolution**: Rolled back configuration to previous pool settings and restarted PaymentService instances.
**Related Deployment**: Deployment #827 (v1.8.2)
